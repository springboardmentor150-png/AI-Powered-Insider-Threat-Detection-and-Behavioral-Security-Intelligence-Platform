# ITBIS Architecture

## Project
AI-Powered Insider Threat Detection and Behavioral Security Intelligence Platform

## Architecture Flow

Users
↓
FastAPI API Gateway
↓
Authentication and Role-Based Access Control
↓
Employee Management
↓
Activity Log Ingestion
↓
Database Layer

## User Roles

- Security Analyst
- SOC Engineer
- Security Manager
- Admin

## Core Components

- Authentication Service
- Employee Management
- Activity Log Ingestion
- Behavioral Profiling
- Anomaly Detection
- Risk Scoring
- Investigation
- Alerting

## Database

Structured data is managed using the relational database layer.

Flexible activity and behavioral data is stored in MongoDB.

## Milestone 1 Scope

- Backend setup
- Frontend setup
- Authentication
- Role-based access control
- Employee profile management
- Basic activity log ingestion
